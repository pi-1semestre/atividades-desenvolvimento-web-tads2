# Resumo da Aula 01 — Apresentação e contextualização

## Front-end

Front-end é a parte da aplicação com a qual a pessoa usuária interage. Ele reúne a interface visual, a experiência de uso, a organização dos elementos e a comunicação com serviços responsáveis pelo processamento dos dados.

O desenvolvimento front-end utiliza três fundamentos principais:

- **HTML:** estrutura e significado do conteúdo;
- **CSS:** aparência, layout e responsividade;
- **JavaScript:** comportamento, interação e comunicação com servidores.

Antes de iniciar o desenvolvimento, é importante definir o escopo, criar protótipos e considerar aspectos de UX para validar a ideia e reduzir retrabalho.

## JavaScript puro

Vanilla JavaScript é o uso de JavaScript sem frameworks ou bibliotecas externas. Ele permite manipular o DOM, responder a eventos e buscar dados em serviços externos. Também serve como base para compreender abstrações utilizadas por React, Vue, Angular e outras tecnologias.

## Frameworks front-end

Frameworks e bibliotecas ajudam a criar aplicações organizadas, reutilizáveis e fáceis de manter. Entre os recursos mais comuns estão:

- componentização;
- gerenciamento de estado;
- navegação por rotas;
- integração com APIs;
- criação de interfaces responsivas;
- testes;
- otimização;
- deploy.

React, Vue e Angular foram apresentados como tecnologias utilizadas no desenvolvimento de interfaces modernas. A escolha deve considerar o problema, a equipe, a complexidade do projeto, a curva de aprendizado e os requisitos da aplicação.

## Versionamento e deploy

- **Versionamento:** registra a evolução do projeto e facilita a colaboração.
- **Git:** mantém o histórico das alterações no projeto.
- **GitHub:** hospeda o repositório e permite o trabalho compartilhado.
- **Deploy:** publica a aplicação para que ela possa ser acessada pela internet.
- **Vercel:** plataforma utilizada para publicar aplicações front-end conectadas ao GitHub.

## Percurso da disciplina

Durante a disciplina serão estudados:

1. configuração do ambiente de desenvolvimento;
2. fundamentos de JavaScript;
3. frameworks CSS e front-end;
4. componentes e construção de interfaces;
5. estado, rotas e gerenciamento de dados;
6. integração com APIs;
7. Git, GitHub e boas práticas;
8. deploy de aplicações.

Ao final, a expectativa é desenvolver interfaces modernas, criar aplicações com frameworks, versionar o trabalho e publicar os projetos na web.

## Metodologia e avaliação

As aulas combinam explicações, discussões, estudos de caso, cenários profissionais e atividades práticas.

| Critério | Peso |
| --- | :---: |
| Desenvolvimento do projeto | 20% |
| Apresentação do projeto | 20% |
| Atividades | 15% |
| Projeto integrador | 35% |
| Autoavaliação | 10% |

O projeto deve ser documentado com informações sobre concepção, planejamento, execução, resultados, desafios, soluções e análise crítica. A apresentação deve demonstrar o processo de gestão, o backlog, as páginas implementadas e o benchmarking.

## Atividades

### Atividade 01 — Projeto com Vanilla JavaScript

Criar um projeto com HTML, CSS e JavaScript, conectar o ambiente de desenvolvimento ao GitHub, versionar o código e publicar a aplicação na Vercel.

### Atividade 02 — Organização do semestre e pesquisa

1. Formar um grupo de 3 a 5 integrantes.
2. Criar no GitHub o repositório principal das atividades.
3. Produzir um resumo da Aula 01 em Markdown.
4. Escolher um framework front-end em grupo.
5. Produzir um relatório técnico em PDF com no mínimo cinco páginas, apresentando características, vantagens, uso no mercado e um exemplo de projeto web.
