# Relatório React — Desenvolvimento Web

Repositório da turma **TADS2** para as atividades da disciplina de Desenvolvimento Web, com foco em fundamentos de Front-end e React.

## Conteúdo

- [Resumo da Aula 1](resumo-aula-01.md): apresentação do desenvolvimento Front-end, JavaScript, frameworks, Git, GitHub, deploy e atividades da disciplina.
- [Relatório técnico sobre React](relatorio-react-desenvolvimento-web.md): fundamentos, arquitetura, vantagens, limitações, aplicações profissionais e exemplo de um painel de tarefas.

## Atividade 2

O relatório técnico apresenta o React como tecnologia para desenvolvimento de interfaces Web, abordando:

- componentes, JSX e props;
- estado, Hooks e fluxo de dados;
- renderização e arquitetura;
- organização de projetos;
- qualidade, acessibilidade, segurança e desempenho;
- aplicações do React no mercado;
- exemplo prático de um painel de tarefas.
